# EventZella – Product Manager BI Dashboard

## Project Overview

This project presents a Business Intelligence dashboard designed for the **Product Manager** of the EventZella platform.
The goal is to provide a clear and interactive view of key performance indicators related to event services, providers, reservations, and overall platform performance.

The dashboard helps decision-makers monitor operational performance and identify opportunities to improve the platform experience.

---

## Objectives

The dashboard was developed to support product-level decision making by allowing the Product Manager to:

* Monitor reservation performance
* Analyze revenue and event demand
* Evaluate provider availability and service capacity
* Track customer satisfaction indicators
* Identify trends in service categories and event types

---

## Main KPIs

The dashboard highlights several key indicators such as:

* Total reservations (YTD)
* Revenue generated from event services
* Provider availability
* Service capacity
* Event distribution by type
* Budget allocation by service category
* Quality score indicators

These metrics allow the Product Manager to quickly understand platform performance and detect potential improvements.

---

## Dashboard Features

The dashboard includes multiple interactive visualizations such as:

* KPI Cards for key performance indicators
* Bar charts for service demand analysis
* Pie/Donut charts for event segmentation
* Tables for provider availability and capacity
* Filters to explore specific service categories

The design focuses on **clarity, consistency, and ease of interpretation** for quick strategic insights.

---

## Technologies Used

* **Power BI** – Data visualization and dashboard creation
* **PostgreSQL** – Data storage and data warehouse
* **Data Warehouse Model** – Star schema with fact and dimension tables
* **GitHub** – Version control and project sharing

---

## Data Disclaimer

The data used in this repository is **illustrative and anonymized**.
No confidential or sensitive company information is included.

The purpose of this project is to demonstrate **Business Intelligence and analytics capabilities** for event platform management.

---

## Project Purpose

This project demonstrates how Business Intelligence dashboards can support **product management decisions** by transforming operational data into actionable insights.

It illustrates how analytics can help optimize services, monitor provider performance, and improve the overall event management ecosystem.
